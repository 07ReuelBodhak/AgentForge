# Evidence Repository

This directory stores verification evidence generated by `strict_tester` and `browser_qa` during task verification.

## Structure
```text
evidence/
├── TASK-001/
│   ├── test-output.txt           # Unit/Integration test runner raw outputs
│   ├── api-verification.log      # API response and contract inspection logs
│   ├── console.log               # Client or server runtime logs
│   └── screenshots/              # Visual/browser verification captures
│       ├── desktop-initial.png
│       └── mobile-responsive.png
└── ...
```

## Evidence Preservation Rules
1. **Lightweight & Objective**: Store concrete test runner outputs, CLI outputs, browser screenshots, and API payload traces.
2. **Zero Credentials/Secrets**: Never write API keys, passwords, bearer tokens, or sensitive environment variables into evidence artifacts.
3. **Reference in Failure/Pass Reports**: Tester and Browser QA cite evidence paths directly in their reports so the Manager and Coder have immediate, reproducible context.
